## Changes and verification

- CUDA and Vulkan matched CPU on 2^24 programs for the W=4 core unary ISA
  on all nine GPUs. CPU/Python checks passed on all tested ISA configurations.
- AMD W=8 submissions initially timed out. Vulkan now uses smaller dispatches
  for wide truth tables and explicit synchronization. Failed W=8 chunks were
  requeued and completed by NVIDIA; binary sweeps used the corrected kernels.
- fast/map_functions.py maps an explicit mathematical catalog, retaining all
  aliases, exact truth tables, program words/disassembly and termination data.
  Each positive match is replayed on every input using sim/machine.py.
- The first cross-check against Claude's Rust maps found 2,003 shared table
  entries with identical witness IDs. The catalogs differ: Rust includes
  compositions; Python includes explicit affine families and signedness.
- For W=4, all 256 affine maps (a*x+b) mod 16 occur in the coverage-winning
  unary ISA. The function-map reports refresh after experiment finalization.

## Composition/interpreter handoff

- Clarify one-byte VALUES versus one-byte total CODE versus one-byte macro IDs.
  Existing W=8 results use 8-bit values but four bytes of code.
- 256 one-byte encodings do not imply 256 different behaviors. Exactly k bytes
  have 256^k encodings, before ISA validity checks and behavioral deduplication.
- Reset-between-stage unary composition of the W=2 NAND/JZ catalog stays at
  exactly 12 functions at every depth (closure checked independently).
- The checked-in Rust unary synthesizer contained `(0..n as u8)` when n=256,
  yielding an empty identity table. Recheck current code and fix if still present:
  `(0..n).map(|x| x as u8).collect()`. Direct lookup precedes that path.
- Current composition resets memory per stage and permits 256 steps per stage.
  It is not equivalent to concatenation under a single global 256-step budget.
- Binary composition requires explicit argument routing and temporary storage.
  Verify generated binary APIs expose both inputs.
- Existing closure enumeration uses a selected basis; its counts are not an
  exhaustive closure of all millions of functions. Check frontier handling
  carefully before claiming a complete depth>=3 closure.
