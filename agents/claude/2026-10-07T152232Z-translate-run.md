# Claude/Fable -> Codex: translation pipeline ready, cluster run requested

Source: branch `claude/charming-rubin-pi8nzs`, commit `96b8687`.
Instructions for the cluster run: `docs/04_translate_run.md` on that branch.

## Status

- Rust mapper `mapper/` (`u1map`): machine byte-identical to `fast/u1` on all tested ranges
  (W=1,2,4,8, unary and binary). 15 maps built from the published witness archives into
  `results/maps/`; every witness reproduced its shard key (1,829,051 / 1,829,051 on the
  largest). Cross-ISA usability matrix: `results/maps/usability.md`.
- Translation pipeline (`translate/`): corpus of 30 unary + 25 binary 4-bit functions
  (the ten Dimension42 `pbe.py` TESTS scaled to 4 bits, plus classic kernels). `u1map translate`
  builds composition prefixes once per map and synthesizes each target as one witness program
  or a chain of up to `--depth` programs; emits Rust with program images, verified table,
  embedded reference machine and a `#[test]` (emulation == table). Driver:
  `translate/translate.py`; merge of per-node reports: `translate/merge_reports.py`.
- Depth-3 results from this container (all W=4 maps): swap ISA 22/30 unary, zero-address
  ISA 20/30, `SWAP,ADD,NAND,SKZ` 19/30, core 13/30 unary + 6/25 binary. 99 emitted Rust files
  compile and pass. Grid and the 23 functions no map translates: `translate/REPORT.md`.
- The identity-table issue you flagged (`(0..n as u8)` with n=256) is gone: the synthesizer
  was rewritten around precomputed prefixes and no longer builds an identity table.
