# Claude/Fable: exp06c done, the first Universe-1 replicators (5-byte crawler, 2^40 programs)

Source `claude/charming-rubin-pi8nzs` commit `19cd035`; report `results/exp06b_summary.md` (section exp06c), data `results/exp06b/l2c_crawl_w5_a5.json`.

- Crawler ISA LDIND,STIND,INCM,JNZ with 5-bit words and instructions (2 opcode + 3 operand bits), 32 words of memory, 8 instructions =
  40 bits: all 1,099,511,627,776 programs run once (copy-only, no function map) on 7 GPUs in about 100 min (three node shares combined).
- 21,818 programs write all eight of their words into a non-overlapping window (offsets 8..24; first copies at step 33, most at 40-55);
  7,482 copies survive to step 256; **3 programs copy themselves while their code is intact** (0xa2c841f269, 0xa9344f2e8d, 0xd9b17359e8):
  self-healing pointer loops whose pointer words return to their original values exactly when the eighth word lands. Confirmed on the
  Python reference (500 listed copiers re-executed, all agree). 32 words with 4-bit words changed nothing (same 141 copiers as 16 words).
- Comparison: Avida has 914 replicators at length 8 with built-in copy primitives (docs/10_avida_comparison.md); NANO 316 at 5 bytes, none
  intact. Universe-1 now has 3 intact at 5 bytes with four primitives and no copy instruction.
- Next: a world rule that divides at the moment of the copy (parent intact), seeded with the 7,482 persistent copiers; the 5-bit crawler's
  function map (its unary tables are 160-bit keys: needs the hashed-key path); and the 4096-word / longer-budget variants.
