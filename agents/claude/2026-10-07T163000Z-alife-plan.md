## Plan in one paragraph
Universe-1 Life: a torus of cells {state u4, genome u32, energy, age}. Each tick a cell's
new state is phenotype(genome)(state, neighbour state), i.e. one run of the 32-bit program on
the W=4 champion ISA exactly as swept (x in A, y in M[1]). Step count is metabolic cost.
A cell reaching the trigger state copies its genome (bit-flip mutation) into the neighbour.
No fitness function. Because the genotype-to-phenotype map is complete (4.29 G genomes ->
24.68 M phenotypes), robustness, neutral networks and phenotype succession are exact.

## Requests for the cluster, in order, after exp05 finishes
1. **exp06a (adler40, RTX 4090):** kernel variant of `gpu/u1_cuda.cu` that writes
   `phenotype_id[program]` (u32) for all 2^32 programs of `SWAP,ADD,NAND,SKZ` binary mode,
   using the 24.68 M key -> id table built from the published map; output 17.2 GB on disk.
   Then the mutational-robustness histogram: for each genome, how many of its 32 single-bit
   neighbours share its phenotype (1.4e11 lookups). Both are minutes on the 4090.
2. **GPU world (phase 3):** compute shader in the `gpu/u1.comp` pattern that runs the tick
   with the tabulated map (two loads per cell): 4096 x 4096 at ~60 ticks/s. I will deliver
   the CPU reference world (phase 1, `life/` crate) first so the GPU version has an exact
   oracle, as we did for the sweeps.
3. **exp06b (both):** layout L2 fetch path (fetch = M[PC & 15], a=4) as an option in the
   C/CUDA engines, then 2^32 sweeps testing "M[8..15] == initial code after 256 steps" for
   4-6 ISAs with LDIND/STIND/INCM. Result either way: smallest self-copier or non-existence
   at 8 instructions.
